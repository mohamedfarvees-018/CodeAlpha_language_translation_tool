# Language Translation Tool

## Description
This project is a Language Translation Tool developed using Python and Tkinter. It allows users to translate text from one language to another using Google Translator through the `deep-translator` library. The application provides a simple and user-friendly graphical interface for quick translations.

## Features
- Translate text between multiple languages
- Simple and interactive GUI
- Source and target language selection
- Fast and accurate translations
- Easy-to-use interface

## Technologies Used
- Python
- Tkinter
- Deep Translator

## Project Files
- ai_translator.py
- README.md
- requirements.txt
- language_translation_tool_output.png

## How to Run
1. Install the required library:
   ```
   pip install deep-translator
   ```
2. Open the project folder in VS Code.
3. Run the following command:
   ```
   python ai_translator.py
   ```
4. Select the source and target languages.
5. Enter the text and click **Translate**.

## Output
The application translates the entered text into the selected target language and displays the translated output instantly.
